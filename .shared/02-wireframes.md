# 02. UI Wireframes (Weekly Mission)

> 版本: v1 (2026-03-28)

## 1) Popup: 本週任務卡 (新增)

```text
+--------------------------------------+
| 翻譯設定                             |
+--------------------------------------+
| [本週任務] Week 12                   |
| 進度: 45%  [█████-----]              |
| - 複習到期詞彙 6/12                  |
| - 強化弱項詞彙 2/5                   |
| - 新增新詞 1/3                       |
| [前往複習]   [查看詳情]               |
+--------------------------------------+
| (既有設定項目...)                     |
| 主題 / 自動翻譯 / 高亮 / ...          |
+--------------------------------------+
```

設計原則:
- 任務卡固定在設定區上方，讓目標先被看見。
- 不擠壓既有控制項，僅新增一個可折疊區塊。

## 2) History: Mission Progress 模組 (新增)

```text
+------------------------------------------------+
| Dashboard                                      |
| 本週任務完成率 45%  (剩 4 天)                    |
| [█████-----]                                    |
| 今日建議: 先完成 4 題到期複習                   |
+------------------------------------------------+
| 詞彙列表...                                     |
```

設計原則:
- 任務摘要放在統計卡區域，不進入每條詞卡，避免資訊噪音。

## 3) Review: 即時任務回饋 (新增)

```text
Question Card

Correct!
[Mission +1] 複習到期詞彙 7/12
```

設計原則:
- 以單行 toast/badge 呈現，不干擾答題節奏。

## 4) Tooltip: 任務標記 (輕提示)

```text
+------------------------------+
| [B1] Rank #850   Mission     |
+------------------------------+
| 放棄                          |
+------------------------------+
```

設計原則:
- 沿用既有 tooltip 樣式，只增加小標籤，不新增浮層層級。

## 5) Options (可選提醒)

```text
[ ] 開啟每日任務提醒 (可選權限)
    每天最多 1 次
```

設計原則:
- 權限說明就近顯示，避免使用者不理解為何請求通知權限。
