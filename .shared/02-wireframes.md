# 02. UI Wireframes (Reading Progress Dashboard)

> 版本: v1 (2026-08-21)

## 1) Popup: 儀表板區塊 (新增於頂部)

```text
+--------------------------------------+
| 📊 Learning Progress                 |
+--------------------------------------+
| +----------+  +----------+           |
| | 🔥       |  | 📚       |           |
| | 12       |  | 347      |           |
| | Streak   |  | Words    |           |
| +----------+  +----------+           |
| +----------+  +----------+           |
| | 📈       |  | ⏱️       |           |
| | +23      |  | 45m      |           |
| | This Mo  |  | This Wk  |           |
| +----------+  +----------+           |
+--------------------------------------+
| 翻譯設定                             |
+--------------------------------------+
```

設計原則:
- 4 個統計卡片, 2x2 網格排列
- 每個卡片: 圖標 + 數字 + 標籤
- 使用品牌色 (teal) 強調重點數字
- 固定在設定區上方, 提升可見度

## 2) Popup: 詞彙成長圖表 (新增於統計卡片下方)

```text
+--------------------------------------+
| Vocabulary Growth         [7D] [30D] |
| +----------------------------------+ |
| |        *                         | |
| |       * *                        | |
| |      *   *                       | |
| |     *     *                      | |
| |    *       *                     | |
| |   *         *                    | |
| |  *           *                   | |
| | *             *                  | |
| +----------------------------------+ |
| Mon  Tue  Wed  Thu  Fri  Sat  Sun   |
+--------------------------------------+
```

設計原則:
- 折線圖, 顯示詞彙累積趨勢
- 右上角切換: 7天 / 30天 / 90天
- Hover 顯示該日新增數量 (tooltip)
- 簡潔, 不引入大型圖表庫

## 6) Streak 提示 (Popup 底部)

```text

| 🔥 Complete today's streak!          |
| Translate or save 1 word today       |
| to keep your streak going.           |

```

設計原則:

## 響應式設計

### Popup (360px 寬)
- 統計卡片: 2x2 網格
- 圖表: 全寬
- 里程碑: 單行

### Dashboard (全頁)
- 最大寬度: 800px, 居中
- 手機版: 單欄排列
- 平板/桌面: 可使用 2 欄
