# UI 增補：Cloud Backup & Cross-Device Sync

## 1. Popup：同步狀態卡片

```text
+--------------------------------------+
| ☁️ Cloud Backup & Sync               |
| 本機模式                              |
| 雲端同步尚未啟用                      |
| [啟用 Google Drive 同步]              |
+--------------------------------------+
```

### 已啟用狀態

```text
+--------------------------------------+
| ☁️ Cloud Backup & Sync       [⋯]     |
| ● 已同步                              |
| Google Account                         |
| 上次同步：2026-08-25 14:30             |
| [立即同步] [查看歷史版本]              |
| [開啟 Google Drive] [登出]             |
+--------------------------------------+
```

狀態色彩不能是唯一提示，必須同時顯示文字與 `aria-live="polite"` 訊息：

- 已同步：綠色圓點
- 同步中：藍色圓點與進度文字
- 待同步/離線：橙色圓點與待處理數量
- 失敗/授權失效：紅色圓點與可操作的重試/重新登入

## 2. 啟用流程

```text
+--------------------------------------+
| 啟用 Google Drive 同步                |
|                                      |
| 會同步單字、SRS、學習統計與設定。      |
| 備份會放在你的 Google Drive 可見資料夾。|
| 來源網址與上下文會以 JSON 保存。       |
|                                      |
| [取消]                 [登入並啟用]     |
+--------------------------------------+
```

登入前必須先顯示資料範圍與明文儲存風險；取消後回到本機模式，不阻擋既有功能。

## 3. 歷史版本 Modal

```text
+--------------------------------------+
| 歷史備份版本                    [×]   |
|                                       |
| ● 目前版本  2026-08-25 14:30          |
|   裝置：MacBook · 1,245 筆資料         |
|   [預覽]                               |
|                                       |
| ○ 2026-08-25 10:12                    |
|   新增 12 · 修改 4 · 刪除 1            |
|   [預覽] [還原]                        |
|                                       |
| ○ 2026-08-24 18:03                    |
|   ...                                 |
|                                       |
+--------------------------------------+
```

最多顯示 7 個版本；預覽結果顯示新增、修改、刪除、衝突與資料總量。還原前需二次確認，還原後建立新的 current 版本。

## 4. 清除資料確認

```text
+--------------------------------------+
| 清除所有學習資料？                    |
|                                      |
| 這會同步刪除其他裝置上的資料。        |
| 可從最近 7 個雲端版本復原。             |
|                                      |
| 請輸入 CLEAR                          |
| [____________________________]         |
|                                      |
| [取消]                 [確認清除]       |
+--------------------------------------+
```

輸入不完全等於 `CLEAR` 時，確認按鈕 disabled；按鈕需有明確的 destructive label。

## 5. 失敗與帳號流程

```text
離線/上傳失敗
  └─ 顯示「本機資料安全保留」
  └─ 顯示下次重試時間
  └─ [立即重試]

帳號切換
  └─ 顯示目前帳號與目標帳號
  └─ 顯示「資料不會自動混合」
  └─ [取消] [停止目前同步並切換]
```

## 6. 可及性與響應式

- Popup 寬度 360px 時，狀態卡片改為單欄；Modal 可垂直滾動。
- 所有狀態以文字、圖示與 `aria-label` 同時表達，不依賴顏色。
- 所有按鈕可用 Tab/Enter 操作；`CLEAR` 輸入錯誤時提供 inline error。
- 同步完成、失敗、恢復成功使用 `aria-live="polite"`，不強制搶焦點。
- 遵循現有 I18nService；包含 Google、Drive、同步錯誤與資料風險說明。
